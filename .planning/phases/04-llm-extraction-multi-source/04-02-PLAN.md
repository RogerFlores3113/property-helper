## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scraped HTML → LLM | Untrusted text content reaches Claude; forced tool_choice prevents prose injection (T-04-01) |
| LLM tool_use output → INSERT | Untrusted structured data; Pydantic Listing model validates ranges before persist (T-04-07) |
| arbitrary URL → Redis key | Hostname-derived key only, no path; short TTL (T-04-06) |
| anthropic_api_key → process env | Read-only via Settings; never logged, never serialized (T-04-04) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | llm_extract.extract — prompt injection via scraped text | mitigate | Forced `tool_choice=_TOOL_CHOICE` (D-01); Claude cannot return prose. System prompt: "Never invent prices or addresses." Pydantic re-validates output. |
| T-04-07 | Integrity | llm_extract.Listing validation | mitigate | Field range constraints reject price>100_000, beds>20, baths>20, sqft>20_000, lat outside ±90, lng outside ±180. Invalid items silently dropped. |
| T-04-04 | Information Disclosure | llm_extract._get_client | mitigate | AsyncAnthropic constructed once via Settings.anthropic_api_key; structlog events never include the key or the raw `text` content. |
| T-04-06 | Tampering | rate_limit.acquire_domain_slot | mitigate | Key prefix is fixed `rate_limit:`; suffix is `urlparse(url).hostname` only (no path/query); PX=1000ms enforces short-lived state; Redis is private to the cluster. |
| T-04-10 | DoS | anthropic SDK retries amplify token spend | mitigate | `AsyncAnthropic(max_retries=1)` per Pitfall 10. |
| Cache-invalidation footgun | Performance/Cost | llm_extract.extract — tool_choice constant | mitigate | `_TOOL_CHOICE` is a module constant; never constructed inline (Pitfall 2). Sonnet escalation reuses the same constant (only model changes). |
